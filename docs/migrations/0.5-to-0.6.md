# Migrating from saml-rs `0.5` to risaml `0.6`

This guide covers the changes consumers need to make when moving from
`saml-rs` 0.5.x to `risaml` 0.6.x, Rhein Industries' maintained fork of
saml-rs. risaml 0.6.0 starts from saml-rs 0.5.0; apart from the points below,
its public API and SAML behavior are those of saml-rs 0.5.0.

## The crate is named `risaml`

Replace the dependency and the import paths:

```toml
[dependencies]
risaml = "0.6"
```

```rust
use risaml::{Saml, SamlError};
```

To keep existing `saml_rs::` paths while migrating, rename the dependency
instead:

```toml
[dependencies]
saml-rs = { package = "risaml", version = "0.6" }
```

The upstream compatibility packages `opensaml`, `samlify`, `rustsaml` and
`samlet` have no risaml equivalent; depend on `risaml` directly.

## XML security comes from ribergshamra

risaml delegates XML-DSig, XML-Enc and C14N to `ribergshamra` 0.10 (Rhein
Industries' fork of bergshamra 0.9.1) on `riptering` 0.6 instead of
`bergshamra` 0.8 on `kryptering` 0.5. Types that risaml's API takes or
returns, such as the `Key` from `crypto::keys::load_private_key`, are now
`ribergshamra` types. Applications that also use bergshamra directly next to
risaml should switch those uses to `ribergshamra` (or
`bergshamra = { package = "ribergshamra", version = "0.10" }`), because
bergshamra 0.8 and ribergshamra 0.10 types are distinct.

## Feature names

The default feature is now `crypto-ribergshamra`. `crypto-bergshamra` remains
as an alias for it, so existing feature lists keep working. The provider and
capability features keep their names: `crypto-rustcrypto`, `crypto-aws-lc`,
`crypto-fips`, `crypto-legacy-algorithms`, `crypto-post-quantum` and
`crypto-pkcs11`.

## RSA key size

With the default features nothing changes. A build that selects
`crypto-rustcrypto` without `crypto-legacy-algorithms` now rejects RSA keys
shorter than 2048 bits, as AWS-LC and FIPS builds already did. Enable
`crypto-legacy-algorithms` if a peer still uses shorter RSA keys.

## MSRV

risaml 0.6 requires Rust 1.88, like saml-rs 0.5.
